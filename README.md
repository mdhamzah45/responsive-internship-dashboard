# Responsive Internship Board

A simple internship listing interface built with semantic HTML, responsive CSS, and vanilla JavaScript. It includes:

- Search by role, company, or skill
- Domain filtering
- Empty and error states
- Keyboard-friendly card navigation
- Responsive layouts for mobile, tablet, and desktop

## Run locally

From the project folder, use one of the following:

```bash
python -m http.server 3000
```

Then open http://localhost:3000 in your browser.

## Project structure

- `index.html` — semantic page structure
- `styles.css` — responsive visual design
- `script.js` — internship data, filtering, and interaction logic

## Notes

This project is built without any framework and focuses on accessible, mobile-first design patterns.
